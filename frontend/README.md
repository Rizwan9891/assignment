# Telecaller Dashboard Frontend

A simple React.js frontend for the Telecaller Dashboard assessment.

## Tech Stack

- React.js
- Vite
- React Router DOM
- Axios
- Tailwind CSS

## Features

- Dashboard
- Orders List
- Search Orders
- Status Filter
- Pagination
- Update Order Status
- Create New Order

## Installation

```bash
npm install
```

## Run Project

```bash
npm run dev
```

## Backend URL
